# ✦ 수련이의 2029 대입 나침반 (SURYEON'S COMPASS 2029)

> **수련이의 빛나는 스무 살 봄을 응원하며**  
> 동탄에서 아빠 김준희가 딸 김수련의 2029학년도 대입을 위해 서울 주요 13개 대학의 최근 3개년(2024~2026학년도) 공식 수시·정시 입시결과와 2028 대입개편 시행계획을 모아 만든 모바일 맞춤형 입시 웹 & 통합 데이터베이스입니다.

🔗 **모바일·PC 웹 바로가기**: **[https://hs-code97.github.io/junhee/](https://hs-code97.github.io/junhee/)**

---

## 주요 기능

1. **인트로 응원 & 30초 사용법 온보딩**
   - 과거 9등급제 입결과 현 고1 5등급제·통합수능을 연결하는 누적 백분위 환산 원리와 활용법을 스와이프 카드로 안내합니다.
2. **2029 맞춤 수시·정시 비교 시뮬레이터 (엑셀 4번 시트 완벽 구현)**
   - **수시 (1,854개 모집단위)**: 5등급제 내신 평균 및 선택적 상위 누적 백분위(%) 입력 시 `안정 / 적정 / 소신 / 상향 / 참고(1등급내 경합)` 실시간 판정 (원점수·평균·표준편차 기반 Z점수 상위% 보조 계산기 내장)
   - **정시 (775개 모집단위)**: 2028 통합수능 대비 3개년 국수탐 평균 백분위(70% 컷) 기준 상대 위치 판정
   - 학과 카드 터치 시 **3개년 연도별 상세 입결(모집·경쟁률·충원·50%·70%컷)**과 **해당 대학 2028 개편 핵심 변화**를 바텀시트에서 한눈에 열람
3. **수시(4,396건) · 정시(2,149건) 원천 DB 조회 & 2028 개편 요약**
   - 서울 주요 13개교(서울대, 연세대, 고려대, 서강대, 성균관대, 한양대, 중앙대, 경희대, 한국외대, 서울시립대, 건국대, 동국대, 홍익대) 본캠퍼스 정원 내 일반전형 공식 입결 수록
4. **원본 6시트 통합 엑셀(`.xlsx`) 원클릭 다운로드**
   - 웹 상단 `엑셀` 버튼 또는 하단 다운로드 링크를 통해 수식이 완비된 원본 엑셀 파일을 내려받을 수 있습니다.
